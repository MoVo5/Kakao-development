카카오 JavaScript Key 설정

카카오 맵 API를 정상적으로 사용하려면 Kakao Developers에서 발급받은 JavaScript 키가 필요합니다.

카카오 개발자 센터 등록 필수 조건:

1. 내 애플리케이션 > 앱 설정 > 플랫폼 > Web 플랫폼 등록

2. 사이트 도메인에 현재 실행 주소(예: http://localhost 또는 실행 URL) 등록
